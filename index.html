How to use this

Every direction comes in two versions, so you can see how far each idea can go before you commit to one.

Baseline is the safe version. It follows the layout rules of the apps your buyers already use every day, like GrabFood and Shopee, so nothing feels strange to a first time user.

Bold is the same direction pushed further. Same screens and same features, but with a real designed look that belongs only to PalengkeHub.

Open each page on your phone first. The app is designed mobile first, and the desktop view is the same app made wider, not a different website.

Pick the direction that feels right. Mixing ideas from two directions is fine, and every page is one standalone HTML file you can open, read and copy from.

In every page

What is inside every page

The ten pages look different, but they all carry the same screens, the same data and the same rules.

Price comparison first

Unit prices on every item, a MURA or MAHAL verdict, and one screen that compares the same product across stalls.

Real content from your repo

Your categories, your tabs, your Tagalog copy and your stall names. Only prices and ratings are stand ins.

Mobile first, desktop too

Built at phone width first. On a laptop the same app simply gets wider, with more columns.

One file, no build step

Each page is a single HTML file with the CSS and JS inside. Open it, read it, copy what you need.
